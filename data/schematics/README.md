# 📁 Minecraft Schematics Directory

Place your WorldEdit / Litematica / Sponge `.schem` or `.schematic` files in this directory.

The `muu-mc` Autonomous Construction Subsystem will automatically detect, parse, calculate Bill of Materials (BOM), and construct them in-game via the MCP tools:
- `muu_mc_list_blueprints`: Lists all blueprints and schematics in this folder.
- `muu_mc_build_structure`: Builds any schematic by its filename (e.g. `blueprint_name: "my_castle"`).
